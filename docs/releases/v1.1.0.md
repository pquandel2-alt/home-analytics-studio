## Home Analytics Studio 1.1.0

### Neu: Dashboards auf dem Fernseher anzeigen
1. Am Fernseher/Tablet einmalig im Browser **`http://<HA-IP>:8100/tv`** öffnen (als Lesezeichen speichern) – es erscheint ein Kopplungscode.
2. Am Handy ein Dashboard öffnen → **„Auf Bildschirm“** → „Neuen Bildschirm koppeln“ → Code eingeben.
3. Danach jederzeit **„Auf Bildschirm“ → Bildschirm wählen → Senden** – der Fernseher wechselt sofort.

Dauerhaft gekoppelt, automatische Wiederverbindung nach WLAN-Abbruch/Neustart, „Identifizieren“, Verwaltung unter *Einstellungen → Bildschirme (TV)*. Nur Lesezugriff, komplett lokal. Die Oberfläche wird jetzt auch für ältere TV-Browser (Samsung Tizen, LG webOS, Fire TV) übersetzt.

Getestet: 102 Backend-Tests, 24 Frontend-Tests, Browser-Ende-zu-Ende-Test „TV + Handy“ (Chromium). Nicht getestet: echter Samsung-/LG-TV-Browser.

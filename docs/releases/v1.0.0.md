## Home Analytics Studio 1.0.0

Erste Veröffentlichung des eigenständigen Analyse- und Visualisierungs-Add-ons für Home Assistant (nur lesender Zugriff, keine Gerätesteuerung).

### Installation
Home Assistant → Einstellungen → Add-ons → Add-on Store → ⋮ → Repositories → `https://github.com/pquandel2-alt/home-analytics-studio` hinzufügen → **Home Analytics Studio** installieren und starten.
Direktzugriff: `http://<HA-IP>:8100` (vorher in der Oberfläche unter *Einstellungen → Benutzer und Sicherheit* einen Benutzer anlegen).

### Highlights
- Eigene Langzeitdatenbank (SQLite/WAL) mit automatischer Verdichtung, resetsicherer Zählerauswertung, Einheiten-/Zeitzonen-/Sommerzeit-Behandlung
- Import von HA-Historie und Langzeitstatistiken, automatisches Nachladen nach Verbindungsabbrüchen
- Visueller Dashboard-Editor: Drag & Drop, Ebenen, Ausrichtung, Undo/Redo, Copy/Paste, responsive Layouts, 35 Widget-Typen, 7 Design-Presets
- Formel-Editor (visuell + Text) mit rückwirkender Berechnung, automatische Analysen ohne KI
- ChatGPT-Export (Prompt/Bericht/JSON), Präsentations-/Kioskmodus, Benutzer & Rollen, Backups mit Integritätsprüfung

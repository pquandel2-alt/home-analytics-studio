## Home Analytics Studio 1.0.1

**Fix:** Die Installation schlug fehl („Can't install ghcr.io/pquandel2-alt/amd64-home-analytics-studio:1.0.0 … denied“), weil `config.yaml` auf ein nicht veröffentlichtes vorgebautes Image verwies. Das Add-on wird jetzt wie vorgesehen lokal auf dem Home-Assistant-Host gebaut (ca. 1–3 Minuten, kein Node.js nötig).

Falls 1.0.0 bereits hinzugefügt wurde: Add-on Store → ⋮ → **Nach Updates suchen**, dann „Home Analytics Studio“ erneut installieren.

## Home Analytics Studio 1.0.2

**Fix:** Der Image-Build auf dem Home-Assistant-Host schlug mit `/bin/ash: pip: not found` fehl. Neuere Supervisor-Versionen übergeben als Basis-Image `ghcr.io/home-assistant/base` (ohne Python) statt des Werts aus `build.yaml`. Das Dockerfile verwendet nun fest das offizielle multi-arch Image `python:3.12-alpine3.20` (amd64/aarch64).

Update: Add-on Store → ⋮ → **Nach Updates suchen**, dann installieren.

## Home Analytics Studio 1.3.0 – Teilen auf Geräte

- **Ein „Teilen“-Symbol:** Im Dashboard öffnet „Teilen“ die Liste deiner Geräte – ein Tipp auf ein Gerät zeigt das Dashboard dort an (aktuelle Seite oder ganzes Dashboard). Geeignete Fernseher aus Home Assistant lassen sich direkt hinzufügen; der Präsentationslink ist als Unterpunkt erreichbar.
- **Samsung-Standardintegration unterstützt:** Kann der Fernseher keine Adresse öffnen („can only play media of type app“), startet das Add-on automatisch die Internet-App, die die zuletzt geöffnete Dashboard-Seite anzeigt, und merkt sich diese Startart. Erlaubt ist nur der Start der Browser-App.
- Ein gekoppelter Fernseher-Browser lässt sich dem verknüpften Fernseher zuordnen – keine doppelten Geräte mehr.
- Fernseher-Auswahl zeigt nur Entitäten, die Medien/Apps starten können.

Getestet: 106 Backend-Tests, 24 Frontend-Tests, Browser-Ende-zu-Ende-Tests (u. a. simulierter Samsung, der Adressen ablehnt und die Browser-App startet).
